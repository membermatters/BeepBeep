# External Dependencies
This directory contains externally managed dependencies that are separate open source projects. With the exception of 
urdm6300 these are maintained by the respective project maintainers and are not part of the core project.

# urdm6300
The urdm6300 library is maintained by us but lives in its own separate repo 
[here](https://github.com/membermatters/urdm6300).

# uwiegand
The uwiegand library is maintained by us but lives in its own separate repo 
[here](https://github.com/membermatters/uwiegand).

# uwebsockets
The uwebsockets library is located [here](https://github.com/danni/uwebsockets).

# micropython-i2c-lcd
The micropython-i2c-lcd library is located [here](https://github.com/brainelectronics/micropython-i2c-lcd).

# ulogging, uos and urequests
These libraries are all part of the pycopy-lib project and can be found 
[here](https://github.com/pfalcon/pycopy-lib/tree/master).
